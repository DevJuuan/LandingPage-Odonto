# Landing Page Clínica Odontológica 

Landing page profissional desenvolvida para uma clínica odontológica em Guarulhos – SP, com foco em apresentar tratamentos, transmitir credibilidade e gerar agendamentos por meio do WhatsApp.

O projeto prioriza design moderno, responsividade, experiência do usuário, otimização para mecanismos de busca (SEO) e estrutura preparada para campanhas de marketing digital.

### ✨ Funcionalidades
- Layout responsivo para dispositivos móveis e desktops.
- Seções de apresentação, tratamentos, diferenciais, perguntas frequentes e contato.
- Botões de agendamento integrados ao WhatsApp.
- Formulário de contato com direcionamento para o WhatsApp.
- Página de Política de Privacidade.
- Estrutura inicial para rastreamento de conversões e integração com ferramentas de marketing.
- Otimização básica de SEO e desempenho.

### 🛠️ Tecnologias
- HTML5
- CSS3
- JavaScript

### 🎯 Objetivo
Desenvolver uma solução web profissional voltada à captação de potenciais pacientes, facilitando o contato com a clínica e oferecendo uma experiência simples, acessível e intuitiva.
